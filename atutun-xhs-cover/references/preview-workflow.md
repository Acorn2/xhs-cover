# 生图后的展示检查

## 可运行的范围

`scripts/preview_covers.py` 读取本地 PNG 与清单，生成离线 HTML：3:4原图、通用基础安全框和无辅助线缩略图。当前仅支持小红书图文与抖音图文，默认不模拟其它比例或视频UI。它只辅助事后验收，不决定平台策略、不修改PNG、不生成新图、不合成文字，也不执行发布。

`report.json` 记录尺寸、建议重排、重要区域裁切及界面重叠。重要区域需要调用者提供；没有标注就只能检查比例，不能称为OCR、人脸识别或适配通过。

坐标在原图上归一化，`box` 为[x,y,w,h]。`position` 为 object-position 的横纵对齐比例，默认[0.5,0.5]。每个关键标题和脸部应单独标注矩形。比例正确的3:4原图不会被裁切；输入比例不符时仅显示风险，不把检查视图当成成品。页面不是平台真实截图。

## 输入

```json
{
  "schemaVersion": 1,
  "topic": "AI智能体科普",
  "variants": [
    {
      "id": "xhs",
      "placement": "xhs-note",
      "style": "03",
      "title": "AI智能体到底是啥？",
      "image": "03-beginner-qa.png",
      "importantRegions": [
        {"label": "标题", "box": [0.07, 0.06, 0.86, 0.32]},
        {"label": "脸部", "box": [0.34, 0.40, 0.35, 0.25]}
      ]
    }
  ]
}
```

图片路径相对于清单文件；拒绝网络URL。仅接受PNG，输出目录必须不存在以避免覆盖。自定义版位尚未接入脚本，清单只能使用 `xhs-note` 或 `douyin-note`。`title`记录期望文案，不把它重新画到已有图片上。

## 使用

在仓库根目录运行：

```bash
python3 atutun-xhs-cover/scripts/preview_covers.py \
  --manifest examples/platform-preview.json \
  --out-dir .tmp/platform-preview-new
```

如果示例目录已存在，改用新的输出目录，不覆盖原交付。安装后也可使用该 Skill 目录下同名脚本。结果包括 `index.html`、`report.json` 和 `assets/`。用系统默认浏览器打开 HTML，逐项查看标题、脸部、标签、边距与小图识别度。

当前示例用一张历史PNG演示检查流程，不代表新生成的两平台对照。两平台需先按各自策略独立生成，最终再用各自的文件和区域标注检查；有警告时修改或重生。旧五版位裁切演示已归档，不再用当前脚本执行。

## 状态与文字

- 生成的报告一律标为 `needs_review`，预览构建成功不代表设计通过。
- `needs_relayout` 是比例或关键区域风险提示；没有风险也仍需目视核对。
- 最终交付的目视检查记录应包含查看的文件、画布与小图、修正内容及仍未核验的平台入口。
- 可编辑文字的后续交接应包含无字底图、标题/断行、字体、颜色和位置；当前脚本不输出PSD、SVG文字图层或最终位图。不可只交一张含字PNG便宣称可编辑。
