# 阿囤囤视觉风格库（01–08）

这些模板定义视觉关系，不绑定平台。阅读前先确定小红书图文或抖音图文的生成策略；下文分区与占比是构图起点，标题、辅助信息与视觉锚点按各自策略安排，不能只替换平台名。用户选择无人物时，以产品、场景或图解为主体，省略五官、手势及人物描边要求。#FDFFA7 是本风格组默认黄色，用户明确给定的品牌配色优先。

人物可以是真人或固定虚拟人物。模板中的“主体呈现方式”和“人物材质”须按所选主体填入：真人使用摄影质感，虚拟人物使用母版画风。选虚拟人物时先读 [固定虚拟人物](virtual-character.md)，将母版特征写入最终提示词，并按品牌色替换默认装饰色；不混入真人摄影要求。背景可为插画场景或真实素材拼贴，保留前后层次即可。

**Hresh 方案的覆盖规则：** 以下浅黄/白色、绿色勾选、彩色横幅和强调短线是通用模板的原始默认值。使用 Hresh 时先应用[当前封面标准](virtual-character.md#当前封面标准)，在最终提示词中将其替换为黑色T恤、亮蓝/明黄字面色、黑白辅助信息和低饱和摄影场景；08保留炭黑底，人物保持手绘。不要原样复制模板后再追加一段相反配色；构图、动作、卡片关系按各风格分别设计。

## 风格一：爆款大字压顶风

顶部超大标题与人物头部紧密衔接，真实场景提供纵深，前景物件与人物形成遮挡，适合强钩子标题、经验公开、教程入口。

### 视觉特征
- 标题：顶部占画面高度35%-43%，最长一行宽约画面85%-92%；通常分成两行，短标题优先使用宽厚字形、紧字距和略微错位的行间关系
- 字效：#FDFFA7/白色填充 → 粗黑描边 → 向右下偏移的厚实黑色硬阴影 → 细白色外轮廓；外轮廓与字面高光分别描述，避免只得到普通黑边字
- 人物：居中偏下，头部紧接标题下缘，躯干自然延伸至画面下部；保留清晰面部、发丝和衣物纹理，人物轮廓优先白色贴纸描边
- 背景：默认真实室内或主题相关工作场景，有可辨认但虚化的环境细节、冷暖光和前后景；用户选择其他背景时保留其选择
- 前景：按主题选择桌面、笔记本电脑、书本或真实内容素材，局部遮挡躯干下部，让半身人物自然落在场景中
- 点缀：一组短标签与一处收益标注即可，围绕肩部和手势安排；箭头连接标注与实际对象，手绘短线强化表情

### 构图执行

先确定标题、脸部、躯干与前景的连续关系，再填充侧边标签。位置比例指可见构图范围，不要求各层面积相加为100%，不同层允许重叠。文字和脸部保留安全边距，桌沿、电脑或身体可以自然出画。

标题直接叠在场景背景上，默认不加规整的黑色圆角大底板；需要衬底时，用局部 #FDFFA7 笔刷划线强化标题。避免把画面拆成互不相关的标题框、人物贴纸和标签区。未指定科技网格时，不以网格渐变替代主题场景；虚拟人物可用同画风的简化环境。

实际生图后逐字检查主标题和标签，包含末尾标点；检查标题外轮廓是否出界、脸部是否遮挡、人物下缘是否自然衔接前景。遇到漏字或漏标点时，优先针对文字局部修正并重新检查。

## 风格二：巨字拆分冲击风

把标题拆成2-4个巨大词块，人物被文字包围或夹在中间，适合"产品经理软技能"、"录音工作大法"这类核心概念。

### 视觉特征
- 标题：拆成多个词块，几乎铺满画面
- 人物：夹在字块之间，动作夸张
- 背景：深色街景、室内、模糊工作场景
- 整体：像短视频封面，强冲击、强节奏

### 提示词模板

```
使用[人物参考编号]保持人物身份，采用[已确定的主体呈现方式与人物材质]，半身构图；虚拟人物保留母版服装、配色与画风。

[具体表情]，人物位于画面中央，占画面约38%，[具体动作：双手指向上方/双手举起/双手打开]，人物边缘有白色或浅黄色 #FDFFA7 描边。

将中文标题"[封面标题]"拆分成[2/3/4]个巨大词块：[词块1]、[词块2]、[词块3]、[词块4]。

词块使用超粗综艺黑体，柔和浅黄色 #FDFFA7 和纯白交替，全部加粗黑描边。词块分别放在画面上方、左侧、右侧和底部，围绕人物排布，部分文字被人物身体轻微遮挡，形成前后层次；如果词块背后有底板或色块，黄色统一使用 #FDFFA7。

背景是[深色或中性背景描述]，轻微虚化，局部有暗角，让 #FDFFA7/白色大字更突出。

加入少量手绘箭头、短横线、感叹号或英文涂鸦小字，数量控制在3个以内，增加街头感和节奏感。

[平台预设比例]封面（[目标版位]），强对比，超大字视觉锤，人物与文字紧密组合但不遮挡眼睛和嘴巴，不超出安全区。
```
